- U3.4 四元数
  - 欧拉角
    - 1.第二个(中间)旋转的轴=90度的时候,会出现万向节死锁
    - 2.同一个旋转的表示不唯一
    - 这两个缺点四元数都可以弥补
  - 四元数概念
    - 三个虚数(组成一个3D向量)+一个实数(组成一个标量)
      - 表示3D空间中的一个旋转量
    - 轴-角对
      - 任意旋转都可以由绕着某个轴(不是空间中XYZ轴)旋转一个旋转角得到
      - +
        - 对于给定旋转，假设为绕着 n 轴，旋转 β 度，n 轴为 (x,y,z)
          - 四元数 Q 则表示绕着轴 n，旋转 β 度的旋转量
        - 那么可以构成四元数为
          - `Q = [cos (β/2), sin (β/2) n]`
          - `Q = [cos (β/2), sin (β/2) x, sin (β/2) y, sin (β/2) z]`
        - 额,四元数又没学过,不需要理解原理,直接带入公式即可
    - 注意(X,Y,Z,W)
      - x, y, z：对应 sin(β/2)·轴分量（和旋转轴、角度都有关）
      - w：对应 cos(β/2)（只和旋转角度的一半有关）
      - <mark style="background-color:#fce7f3;">不是直接对应旋转轴和旋转量!!!!!</mark>
        - <mark style="background-color:#fce7f3;">所以单位四元数(0,0,0,1),代表不旋转</mark>
  - 代码
    - `Q = Quaternion.AngleAxis (角度，轴);`
    - 比如绕x轴60度
      - 直接用API
        - `Quaternino q = Quaternion.AngleAxis (60, Vector3.right);`
          - ## <mark style="background-color:#fce7f3;">带 Angle / 欧拉角 → 传角度</mark>
            - <mark style="background-color:#fce7f3;">而且不能传入角度,会报错</mark>
          - ## <mark style="background-color:#fce7f3;">带 Mathf / 向量数学 → 传弧度</mark>
      - 或者手搓带入公式
        - `Quaternion q_ = new Quaternion(Mathf.Sin(30 * Mathf.Deg2Rad), 0, 0, Mathf.Cos(30 * Mathf.Deg2Rad));`
          - 这里传入的就是弧度了
      - 然后就可以指定物体旋转了
        - `GameObject obj = GameObject.CreatePrimitive(PrimitiveType.Cube);`
        - `obj.transform.rotation = q;`
    - 如果想要让物体逐渐移动
      - `transform.rotation*=Quaternion.AngleAxis(1, Vector3.up);`
        - Update里面四元数相乘(即旋转四元数)
        - 四元数没法用+=实现角度叠加
      - 错误写法
        - `e = transform.eulerAngles;e.z += 1;transform.rotation = Quaternion.Euler(e);`
          - 会卡死,
  - 四元数的计算
    - 四元数相乘
      - 两个四元数相乘得到一个新的四元数,代表两个旋转量的叠加
        - 注意是相对于自身坐标系的旋转
      - `Quaternion q = Quaternion.AngleAxis(20, Vector3.up);`
      - `this.transform.rotation = this.transform.rotation * q;`
        - 物体(已经有旋转量)绕着Y轴再转20度
    - 四元数乘向量
      - 四元数乘向量返回一个新向量
        - 可以将指向向量旋转对应四元数的旋转量,相当于旋转向量
      - `Vector3 v = Vector3.forward;`
      - `v = Quaternion.AngleAxis(45, Vector3.up) * v;`
        - 注意前后顺序不能变,向量放前面就报错
  - 四元数和欧拉角转换
    - 欧拉角转四元数
      - `Quaternion.Euler(x,y,z)`
    - 四元数转欧拉角
      - `Quaternion q;`
      - `q.eulerAngles`
    - 代码举个例子喵
      - 欧拉角转四元数
        - `Quaternion q2 = Quaternion.Euler(60, 0, 0);`
      - 四元数转欧拉角
        - `print(q2.eulerAngles);`
      - 给物体设定旋转
        - `obj2.transform.rotation = q2;`
      - 设定四元数也可以打印出其欧拉角
        - `print(q2.eulerAngles);`
  - 四元数常用方法
    - 单位四元数
      - `print(Quaternion.identity);`
        - 单位四元数0,0,0,1代表不旋转
      - `Instantiate(testObj, Vector3.zero, Quaternion.identity);`
        - 复制个物体处于坐标原点,旋转为0
    - 四元数
      - 由于算法不同,四元数中SLerp速度慢一点点,但是效果更好,建议SLerp
      - 无限接近 先快后慢
        - `A.transform.rotation = Quaternion.Slerp(A.transform.rotation, target.rotation, Time.deltaTime);`
      - 匀速变化 time=1到达目标
        - `B.transform.rotation = Quaternion.Slerp(start, target.rotation, time);`
    - 向量指向转四元数
      - `Quaternion.LookRotation(面朝向量);`
        - ![image-1](https://document-image.mubu.com/document_image/32569566_f5013cbd-57b3-424d-9ecf-9ca9c32a5f8a.png?x-tos-process=image/resize,w_118)
        - A想要改为朝向B,在这个方法中传入AB向量即可
      - 得到AB间的向量,然后旋转
        - `Quaternion q = Quaternion.LookRotation(lookB.position - lookA.position);`
        - `lookA.rotation = q;`
    - 剩下很多方法大概率用不上
