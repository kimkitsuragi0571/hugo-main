  - **static void Main(string[] args)**
    - <mark style="background-color:#fde8e8;"> **必须是静态的（static）** </mark><mark style="background-color:#fde8e8;">：因为程序启动时还没有创建任何类的实例，静态方法无需实例即可执行；</mark>
    - Java 的程序入口必须是 public static void main(String[] args)
      - public：必须加，否则 JVM 无法访问这个方法（C# 可省略）；
      - 方法名必须是小写 main，写成 Main 会被识别为普通方法，不是入口。
      - String[] args：参数名可以改（比如改成 String[] params）
        - 只是个参数名,写成X都可以
    - C++就是朴实无华的int main()
  - **参数可选** ：string[] args 用于接收命令行参数（比如运行程序时传入的参数）；
  - **返回值可选** ：void 无返回值，int 可返回退出码（0 表示正常，非 0 表示异常）；
  - **`一个程序只能有一个可执行的 Main 方法`** ：如果多个类有 Main，需要在项目属性中指定 “启动对象”。
  - **启动方法** ：侧重 “程序启动时第一个执行的方法” 这一特性；
  - <mark style="background-color:#fde8e8;">如果改为  static int Main(string[] args)</mark>
    - <mark style="background-color:#fde8e8;">return 0代表程序正常执行</mark>
    - <mark style="background-color:#fde8e8;">return 1则是代表程序异常执行</mark>

    - Parse<mark style="background-color:#fef3c7;">字符串转化为任意类型</mark>
      - <mark style="background-color:#fef3c7;">Parse是专门将string转化为其他类型的变量</mark>
      - 参数字符串需要可以转化为对应的类型
        - ![image-1](https://document-image.mubu.com/document_image/6d13bef1-c53a-4532-912d-4ecc8701760f-32569566.jpg?x-tos-process=image/resize,w_400)
        - enum.Parse()就是数字和成员都可以,但是前面要加上个typeof(),不然谁知道是枚举
          - 重载
          - ![image-1](https://document-image.mubu.com/document_image/32569566_82b8dfca-6a25-48ee-8ef5-1b5a293fcb8a.png?x-tos-process=image/resize,w_400)
          - Type类型就是给Enum.Parse指明 “要把字符串解析成哪一种枚举” 的 “类型标识”，比如typeof(E_stuLevel)就是告诉它：把 "A" 解析成E_stuLevel这个枚举里的成员，而不是其他枚举。
        - 枚举类型转化的细节
          - <mark style="background-color:#fef3c7;">如果想输入string,打印出枚举(string)</mark>
            - E_QQType qqType = (E_QQType)Enum.Parse(typeof(E_QQType), inputStr, true);
            - 用枚举类型来接收字符串转枚举就行
              - 这个方法前面Parse()那里有笔记
              - <mark style="background-color:#fde8e8;">这里前面必须加上(E_QQType)</mark>
                - 因为Enum.Parse()返回的是一个通用枚举类型object
                - 并不是我们希望的枚举类型E_QQType
                - 并且参数中typeof(E_QQType)只是确定了依据哪种枚举的规则来解析传入变量inputStr,并没有规定返回值类型(默认为object)
      - <mark style="background-color:#fef3c7;">如果想要接收输入的int类型变量</mark>
        - int num = int.Parse(Console.ReadLine());
        - 输入的始终是字符串,你这里还要转化一遍
  - 对字符串不能直接转化为对应的ascii码,没法直接(int)numstr;
    - 要么int.Parse()
      - 当然还有double.Parse()和Enum.Parse()
    - 要么Convert.ToInt32()
