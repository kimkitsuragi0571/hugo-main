- GameObject
  - 成员变量
    - 物体名字
      - `this.gameObject.name`
        - 为什么设计成小驼峰写法呢,很神秘
    - 是否激活
      - `this.gameObject.activeSelf`
    - 是否静态
      - `this.gameObject.isStatic`
        - 静态可以在面板右上角修改
        - 设置为静态obj的优势
          - 可以提前烘光照,不需要运行时计算
          - 可以提前碰撞检测,不需要每帧检测
          - 剔除优化Occlusion,计算哪些物体被遮挡,不需要渲染
    - 所在层级
      - `this.gameObject.layer`
    - 所在标签
      - `this.gameObject.tag`
    - 位置信息
      - `this.gameObject.transform`
        - 等价于直接`this.transform`
    - 补充
      - IDE容易直接补全为this.GameObject,但是注意是驼峰命名法
      - 如果引入外部GameObj
        - `public GameObject Sph;`
          - <mark style="background-color:#fef3c7;">如果面板中也挂载给Sph赋值,则以脚本中为准,直接覆盖掉手动挂载</mark>
        - 两种都行
          - `Sph.gameObject.isStatic`
          - `Sph.isStatic`
  - 静态方法
    - 概念
      - 直接是GameObject类名.方法名 调用,所以是静态方法
      - <mark style="background-color:#fef3c7;">Unity中的Object类是GameObject的父类</mark>
        - <mark style="background-color:#fef3c7;">(命名空间是UnityEngine)并非万物之父Object(命名空间System)</mark>
        - 这个假的Object同样继承自万物之父Object
    - 增删
      - 创建物体
        - 创建默认几何体
          - `GameObject cube = GameObject.CreatePrimitive(PrimitiveType.Cube);`
            - PrimitiveType 是 Unity 里的一个「枚举」专门用来存默认几何体
            - 等价手动右键创建了个Cube,位置在(0.0.0)
            - 之后就可以得到这个几何体的各种信息
              - [cube.name](http://cube.name)
              - `cube.transform.posittion`
        - 创建空物体
          - `GameObject obj6 = new GameObject();`
        - 创建带名字空物体
          - `GameObject obj7 = new GameObject("创建的空物体");`
        - 创建带组件空物体
          - `GameObject obj8 = new GameObject("空物体", typeof(Run), typeof(Speak));`
            - 后面就是要添加的组件
            - 这种方法只能创建空物体添加组件,不能直接创建3DObject
              - 实在想要创建只能用添加网格组件的方法
      - 销毁物体
        - 立即删除对象
          - `GameObject.Destroy(obj)`
            - 实际是标记为删除,下一帧才会真的删除
        - 延迟5秒删除
          - `GameObject.Destroy(myObj, 5);`
        - 删除自身物体
          - `GameObject.Destroy(this.gameObject);`
        - 立即同步删除
          - `GameObject.DestroyImmediate(myObj);`
        - 继承mono的类可以不写GamObject
          - 因为继承mono的类必须挂载到obj上,高度绑定?
          - Mono简写删除
            - `Destroy(myObj);`
          - Mono简写同步删除
            - `DestroyImmediate(myObj);`
      - 复制物体
        - `public GameObject myObj;`
        - `GameObject clone = Instantiate(myObj);`
          - 也可以不用obj接收,这样只是声明
          - 单例里面的`instance = Instantiate(this);`
            - 把当前脚本实例变成全局唯一的单例
            - ![image-1](https://document-image.mubu.com/document_image/32569566_f20e5b56-6347-4fbd-b4d9-c7245a799889.png?x-tos-process=image/resize,w_217)
    - 查找(<mark style="background-color:#fde8e8;">都只能找激活物体</mark>)
      - 查找单个物体
        - `GameObject obj =  GameObject.Find("物体名")`
          - 直接遍历场景中所有物体,所以效率低
          - 没法通过名字找到多个物体
      - 按标签查找单个
        - `GameObject obj = GameObject.FindWithTag("Player")`
          - 如果有多个对象满足条件,没法具体确定找到的是谁
          - 和FindGameObjectWithTag没有任何区别
          - 失活的对象找不到
      - 按标签查找多个
        - `GameObject[] arr =  GameObject.FindGameObjectsWithTag("Player")`
          - 同样只能找激活物体
      - 查找指定组件
        - `Player player = FindObjectOfType<Player>();`
          - 遍历所有激活的obj,找到第一个指定的组件
          - <mark style="background-color:#fef3c7;">注意返回的是组件而不是obj本身</mark>
          - <mark style="background-color:#fef3c7;">总之效率很低,基本不用</mark>
      - 能找失活物体的
        - ![image-1](https://document-image.mubu.com/document_image/32569566_936fef0e-8a01-4a8f-807b-09496ae44208.png?x-tos-process=image/resize,w_258)
    - 组件相关
      - 为对象添加组件(老写法)
        - `Run run = obj.AddComponent(typeof(Run)) as Run;`
          - 如果继承mono类能实例化,直接在脚本里面Run run = new Run();
            - 然而不能,所以用Unity给的方法
          - 同样可以脚本换成Transform组件之类的
          - 也可以不接收返回值,这里只是方便(添加了XX组件就顺带拿来修改)
      - 为对象添加组件(泛式写法)
        - `Run run = obj.GetComponent<Run>();`
          - 这个常用多了
          - 如果添加组件并修改选项值
            - ![image-1](https://document-image.mubu.com/document_image/32569566_aae5fe93-5316-487b-a244-01c4d18a9393.png?x-tos-process=image/resize,w_279)
    - 其他
      - 比较标签(两种方法等价)
        - `if(this.gameObject.CompareTag("Player"))`
        - `if(this.gameObject.tag == "Player")`
      - 切换场景保留物体
        - `GameObject.DontDestroyOnLoad(this.gameObject);`
          - 切换场景会导致当前场景所有物体都被删除
          - 单例模式也会用到
        - `DontDestroyOnLoad(this.gameObject);`
      - 设置激活状态
        - 物体激活
          - `obj6.SetActive(true);`
            - enabled是管理脚本的激活失活
            - 这个是管理游戏物体的激活失活
        - 物体失活
          - `obj6.SetActive(false);`
        - 组件激活
          - `collider.enabled = false;`
            - Collider组件有enabled方法
            - <mark style="background-color:#fde8e8;">刚体组件没有enabled方法,想要关闭有两种方法</mark>
              - 直接销毁组件
                - `Destroy(GetComponent<Rigidbody>());`
              - 禁用物理（模拟关闭）
                - `rb.isKinematic = true;`
              - 或者关掉重力?
      - 消息发送
        - 自身发送
          - `this.gameObject.SendMessage("TestFun");`
            - 命令自身物体执行XX函数
              - 遍历自身所有脚本找到对应名字
            - 如果有多个脚本,且有重名函数,就会均执行
            - 生命周期函数会自动执行,但是自己写的函数比如Speak()不会执行
        - 自身带参发送
          - `this.gameObject.SendMessage("TestFun2", 199);`
        - 广播（自身+子对象）
          - `this.gameObject.BroadcastMessage("函数名");`
        - 向上发送（自身+父对象）
          - `this.gameObject.SendMessageUpwards("函数名");`
- Time
  - 时间缩放比例
    - 时间停止
      - `Time.timeScale = 0;`
  - 帧间隔时间
    - 帧间隔时间概念
      - 主要是用来计算位移
      - 路程 = 时间 * 速度
      - 最近的一帧 用了多长时间（秒）
    - 受Scale影响
      - `print("帧间隔时间" + Time.deltaTime);`
        - 游戏暂停时不动
    - 不受Scale影响
      - `print("不受scale影响的帧间隔时间" + Time.unscaledDeltaTime);`
        - 不受暂停影响
  - 物理帧间隔时间 FixedUpdate
    - 受scale影响
      - `print(Time.fixedDeltaTime);`
    - 不受scale影响
      - `print(Time.fixedUnscaledDeltaTime);`
  - 帧数
    - 从开始到现在游戏跑了多少帧(次循环)
      - `print(Time.frameCount);`
