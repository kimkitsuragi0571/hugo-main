- Vector
  - Vector创建
    - 两种声明后赋值
      - `Vector3 v = new Vector3();`
        - `v.x = 10;v.y = 10;v.z = 10;`
        - <mark style="background-color:#fde8e8;">这只是个数字,实际代表向量/点/欧拉角,需要看传入的方法</mark>
      - `Vector3 v4;`
        - `v4.x = 10;v4.y = 10;v4.z = 10;`
        - 只是Vector3的话是可以修改单独值的,transform.position就不行了
    - 只传xy，默认z=0
      - `Vector3 v2 = new Vector3(10, 10);`
    - 传xyz
      - `Vector3 v3 = new Vector3(10, 10, 10);`
  - Vector常用方法
    - <mark style="background-color:#fef3c7;">计算两点间距离</mark>
      - `float distance = Vector3.Distance(v1, v12);`
  - Vector常用静态属性
    - ![image-1](https://document-image.mubu.com/document_image/32569566_3f8c5fc1-c7f1-498e-c5d3-141227c8cc82.png?x-tos-process=image/resize,w_500)
      - Vector3用于表示一个向量(3,2,4),相当于从世界坐标系下(0,0,0)到(3,2,4)
      - 至于起点不用在意,向量是可以随便平移的
      - <mark style="background-color:#fde8e8;">区分Vector3模长的作用</mark>
        - <mark style="background-color:#fde8e8;">用Translate和普通+=方法时,Vector3的模长/旋转量也是会决定移动/转速的,不只是指定方向</mark>
        - <mark style="background-color:#fde8e8;">只有用Rotate方法的时候,Vector3就只是指定旋转方向,不影响速度</mark>
          - 想要模长决定旋转速度,就用Rotate重载(下面有写)
- Transform位置
  - 位置实例属性
    - 坐标
      - <mark style="background-color:#fef3c7;">相对世界坐标系</mark>
        - `this.transform.position;`
          - （绝对位置）
          - 作为一个属性肯定是有返回值的,类型是Vector3
            - `Vector3 currentPos = transform.localPosition;`
            - `transform.localPosition = new Vector3(1, 2, 3);`
      - <mark style="background-color:#fef3c7;">相对父对象</mark>
        - `this.transform.localPosition;`
          - (局部位置，和面板显示一致)
    - 朝向
      - ![image-1](https://document-image.mubu.com/document_image/32569566_2c0f4aef-bdee-4ef5-bc39-7d20448dc6ea.png?x-tos-process=image/resize,w_175)
        - vector里面的朝向是静态属性,而transform里面的是实例属性
          - Vector3 是「数学工具类」，Transform 是「物体实例」
        - 一个只是数字,一个固定是局部坐标系Y轴正向
  - 直接修改位置
    - `this.transform.position.x = 10;`<mark style="background-color:#fde8e8;">错误的,不能单独修改xyz</mark>
    - `this.transform.position = new Vector3(10, 10, 10);`
      - 必须重新整体赋值Vector3
    - 如果想修改单独的值
      - 直接赋值的时候保留
        - `this.transform.position = new Vector3(10, this.transform.position.y, this.transform.position.z);`
      - 取出来修改然后赋值
        - `Vector3 vPos = this.transform.localPosition;`
          - get方法return个vector3
          - transform.position返回值就是个Vector3值
        - `vPos.x = 10;`
        - `this.transform.localPosition = vPos;`
          - set方法,直接设置
- Transform位移
  - 概念
    - 首先理解关于Vector到底指向谁
      - Vector3.forward的值永远是(0,0,1),本身只是个数值,并没有指定是 世界/自身坐标系 的向量
      - <mark style="background-color:#fef3c7;">是我们调用的修改方法决定的</mark>
        - ### <mark style="background-color:#fde8e8;"> **直接修改 position → 永远默认是 世界坐标系** </mark>
        - ### <mark style="background-color:#fde8e8;"> **Translate API → 永远默认是 自身坐标系** </mark>
    - 然后是transform.forward
      - <mark style="background-color:#fef3c7;">注意不是transform.position.z</mark>
        - 这个是坐标的Z值
      - 日你哥,实际值就是"<mark style="background-color:#fef3c7;">局部坐标系Z轴正向</mark>"的方向
        - 网上全tm是抽象解释,我服了
        - <mark style="background-color:#fef3c7;">但是这里transform.forward是已经转化为世界坐标下的值</mark>
        - 或者说,<mark style="background-color:#fde8e8;">世界坐标系下创建一个轴,其指向和局部坐标系Z轴正向相同</mark>
  - 计算位移
    - 相对自身坐标系移动
      - `this.transform.position += this.transform.forward *1 * Time.deltaTime;`
        - 1.两种保持稳定的区别
          - ![image-1](https://document-image.mubu.com/document_image/32569566_5024af40-2c33-470b-b433-94a9209bbb1d.png?x-tos-process=image/resize,w_314)
        - 2.同时添加两个方向的移动仍然是指向运动
          - 需要有加速度才会有曲线运动
        - <mark style="background-color:#fce7f3;">3.Time.deltaTime的作用</mark>
          - 首先Update是一帧更新一次,60帧和30帧的人一帧分别是1/60和1/30秒
            - 一秒分别跑60和30米
          - 乘以deltaTime后,修改每一帧的时长
            - 过程我不想理解了
            - <mark style="background-color:#fce7f3;">总之结果从一帧跑一米,变成了一秒跑一米</mark>
    - 相对世界坐标系移动
      - `this.transform.position += Vector3.forward * 1 * Time.deltaTime;`
      - Vector默认是世界坐标系下的(0,0,1)
  - API位移(一般用这个来移动)
    - 自身坐标系下,Vector指定位移
      - `this.transform.Translate(Vector3.forward * 1 * Time.deltaTime, Space.Self);`
      - API中的Vector,默认指定自身坐标轴下的(0,0,1)
        - 这里不写第二个参数就是默认自身坐标系
    - 世界坐标系下,Vector指定位移
      - `this.transform.Translate(Vector3.forward * 1 * Time.deltaTime, Space.World);`
      - 现在就是指定为世界坐标系下的(0,0,1)
    - 世界坐标系下,transform指定方向
      - `this.transform.Translate(this.transform.forward * 1 * Time.deltaTime, Space.World);`
      - 指定朝自身Z轴正方向移动,Unity将自身Z 轴翻译成 “世界坐标下该朝哪”
    - 自身坐标系下,transform指定方向
      - `this.transform.Translate(this.transform.forward * 1 * Time.deltaTime, Space.Self);`
      - <mark style="background-color:#fce7f3;">错误用法!!!!!!!</mark>
        - 本来就是世界坐标系下局部坐标系中Z轴正向的值
        - 你这里把这个值当成在局部坐标系下,又转化了一次
- Transform角度和旋转
  - 获取
    - 相对世界坐标系的欧拉角
      - `this.transform.eulerAngles;`
      - 欧拉角的旋转必须是XYZ按顺序旋转
        - 所谓万象死锁概念
        - 比如你想得到一个飞机的朝向,YZX顺序旋转得到的欧拉角就是错误的
    - 相对父对象的局部欧拉角
      - `this.transform.localEulerAngles;`
      - 和面板显示一致
    - 旋转四元数
      - `this.transform.rotation`
      - 得到的返回值是四元数,这个第二部分讲
  - 计算
    - 普通计算
      - 同样每一帧加上固定角度实现不停变化,<mark style="background-color:#fde8e8;">实际不能用!!!!</mark>
      - this.transform.eulerAngles+=Vector3.up*(1*Time.deltaTime);
        - 因为欧拉角是一个上限360的值,不能+=无限叠加
        - 实际效果就是转一下就停止了
    - API计算
      - 绕轴自转
        - 基本
          - 绕世界坐标系X轴
            - `this.transform.Rotate(Vector3.right, 10 * Time.deltaTime, Space.World);`
              - 第一个参数指定方向,第二个制定速度
              - 和Translate的参数区分开,格式不一样
            - `this.transform.Rotate(new Vector3(10, 0, 0) * 10 * Time.deltaTime, Space.World);`
              - 注意也是要指定Vector3(旋转轴向)在哪个坐标系下面
          - 绕自身坐标系X轴
            - `this.transform.Rotate(Vector3.right, 10 * Time.deltaTime, Space.Self);`
        - 补充
          - <mark style="background-color:#fde8e8;">这里Vector只是设置旋转轴向</mark>
            - 所以new Vector3(10, 0, 0) 和 new Vector3(30, 0, 0)完全一样
            - 注意Translate和两种+=就会影响速度,只有这个不影响
          - <mark style="background-color:#fce7f3;">如果想要让Vector决定旋转速度,要用这个重载</mark>
            - `transform.Rotate(旋转角度Vector3);`
              - `transform.Rotate(new Vector3(10, 20, 30));`
              - `transform.Rotate(new Vector3(10, 20, 30), Space.Self);`
              - ### <mark style="background-color:#fce7f3;">这里的 Vector3 三个数字 全部都是角度,没有一个数字是 “轴”</mark>
                - <mark style="background-color:#fce7f3;">但是可以指定世界/局部坐标系</mark>
                - <mark style="background-color:#fce7f3;">因为要指定绕着哪个坐标系的XYZ轴旋转</mark>
              - 三轴旋转,实际参数中并没有指定轴
            - <mark style="background-color:#fef3c7;">但是这个重载已经不是绕轴旋转了</mark>
      - 绕点自转
        - `this.transform.RotateAround(Vector3.zero, Vector3.right, 10 * Time.deltaTime);`
          - 三个参数:旋转中心,旋转轴,旋转速度
          - <mark style="background-color:#fce7f3;">这个方案中Vector3只能是世界坐标系下!!!</mark>
            - 这个方法的意义就是公转,所以必须是世界坐标系?
          - <mark style="background-color:#fce7f3;">模长不影响转速</mark>
        - 没有绕轴旋转那样的重载,必须是三个参数RotateAround(点, 轴, 角度);
          - 对比上面那个,这是单轴旋转,必须指定轴
          - 作为轴,所以这里Vector的模长也无所谓了
- Transform缩放
  - 获取缩放
    - 相对世界坐标系的缩放
      - `print(this.transform.lossyScale);`
      - <mark style="background-color:#fce7f3;">只读</mark>
        - 因为lossyScale是一个实时计算的值,而不是存储的数据
          - 父物体的lossyScale × 自身的localScale...总之是和场景实时关联的
        - Unity技术上也没法实现transform.Scale
          - 根本就没有也不能有这个属性
    - 相对本地坐标系（父对象）的缩放
      - `print(this.transform.localScale);`
      - <mark style="background-color:#fef3c7;">可读写</mark>
        - 只和自己的父对象有关,所以可以当成数据存储
        - 同样不能只改xyz
          - `this.transform.localScale = new Vector3(3, 3, 3);`
          - this.transform.localScale.x = 3;错误的
  - 调整缩放
    - <mark style="background-color:#fef3c7;">Unity并没有提供缩放的API</mark>
      - 因为没法设置基于世界坐标系的缩放,所以不需要API了
    - `this.transform.localScale += Vector3.one * Time.deltaTime;`
      - 只可能表示局部坐标系下
- Transform朝向
  - 让物体朝向指定坐标
    - `this.transform.LookAt(Vector3.zero);`
      - 放在Start就只调整一次方向
      - 放在Update里就一直指向
        - 直线运动的物体,当到达指向点的时候就停下不动了
  - 让物体朝向指定对象
    - `public Transform lookAtObj;`
    - `this.transform.LookAt(lookAtObj);`

- Transform坐标转换
  - 世界坐标系 → 本地坐标系
    - 点的转换,受物体缩放影响
      - `print(this.transform.InverseTransformPoint(Vector3.forward));`
      - ![image-1](https://document-image.mubu.com/document_image/32569566_9f46fb82-a954-4b2b-8d09-376f54a06fbf.png?x-tos-process=image/resize,w_160)
        - <mark style="background-color:#fef3c7;">世界上一点(0,0,1),现在求其在当前物体局部坐标系下的位置</mark>
        - 原理是求这一点相对于局部坐标系原点O'的位置
      - 为什么会受缩放影响?
        - obj局部坐标系原点O'确实没有改变位置,但是局部坐标系的"单位长度"变了
          - 世界坐标系 1 单位 = 1 米,
          - 物体没缩放时（scale=1,1,1），局部 1 单位 = 世界 1 单位 = 1 米
        - 物体本身需要处理"相对自身"的数据,所以没法放大两倍粗暴记录为2米
    - 向量的转换,受物体缩放影响
      - `print(this.transform.InverseTransformVector(Vector3.forward));`
      - ![image-1](https://document-image.mubu.com/document_image/32569566_d6f73e45-4916-4db7-990d-823f5edd4afd.png?x-tos-process=image/resize,w_181)
        - <mark style="background-color:#fef3c7;">世界坐标系上一个向量,求其在当前物体局部坐标系下的位置</mark>
        - 原理是把向量起点从O移动到O'上
        - 这里Vector视为一个(0,0,1)向量了
  - 本地坐标系转世界坐标系
    - 点转换
      - `this.transform.TransformPoint(Vector3.forward)`
        - ![image-1](https://document-image.mubu.com/document_image/32569566_4a0fa5a6-7a9f-41ab-d852-6510843e9c5b.png?x-tos-process=image/resize,w_210)
        - 从相对O'的(0,0,1)转化为相对O的
    - 向量转换
      - `this.transform.TransformVector(Vector3.forward)`
    - 方向转换,不受缩放影响
      - `this.transform.TransformDirection(Vector3.forward)`
- Transform修改
  - 修改位置
    - 直接赋值（绝对位置）
      - `// 世界坐标transform.position = new Vector3(1, 2, 3);`
    - 相对移动（走一步）
      - `// 本地坐标（相对父物）transform.localPosition = new Vector3(1, 2, 3);`
  - 修改旋转
    - 直接设置欧拉角（最常用）
      - `// 世界欧拉角transform.eulerAngles = new Vector3(0, 90, 0);`
      - `// 本地欧拉角（相对父物体）transform.localEulerAngles = new Vector3(0, 90, 0);`
    - 旋转一定角度（相对旋转）
      - `// 自身旋转（Y轴转1度）transform.Rotate(0, 1, 0);`
      - `// 绕世界轴旋转transform.Rotate(0, 1, 0, Space.World);`
  - 修改缩放（Scale）
    - ### 直接设置缩放
      - `// 每帧变大一点transform.localScale += new Vector3(0.01f, 0.01f, 0.01f);`
