- Single图片编辑
  - ![image-1](https://document-image.mubu.com/document_image/32569566_ab9b9d58-2d4f-4a10-be42-1ac2c7e20bf9.png?x-tos-process=image/resize,w_400)
  - 创建精灵图后点击右下角的SpriteEditor即可打开编辑器
    - 如果是3D工程,需要额外导入2D Sprite包才能使用
  - ![image-1](https://document-image.mubu.com/document_image/32569566_a769aab5-b66f-4d41-b773-bb65825f422d.png?x-tos-process=image/resize,w_400)
    - 这节是图片在Single模式下的编辑
  - 左上角可以选择不同模式
    - SpriteEditor(基础图片设置)
      - **Name** : 名字
        - 额,不能在这里改名字
      - **Position** : 在图片中的偏移位置和宽高
        - 单张图片就不需要修改了,默认左下角是(0,0)
      - **Border** : 边框，用于设置九宫格的 4 条边
        - 通过4条边把物体分为9格
        - 学这个之前已经讲过GUI了?
      - **Pivot** : 轴心（中心）点位置
      - **Pivot Unit Mode** : 轴心点单位模式
        - **Normalized** : 标准化模式，0~1
        - **Pixels** : 像素模式
      - **Custom Pivot** : 自定义轴心点
      - 修改后一定要点上方的Apply
    - Custom OutLine(决定渲染区域)
      - 默认渲染就是把透明的部分也渲染了,最终是两个三角面片组成的正方形
      - 浪费性能,用这个选项就可以自定义渲染的不规则图片边缘形状
      - 选这个模式后上方栏右边多了些选项
        - Snap: 将控制点贴近在最近的像素
        - Outline Tolerance: 轮廓点的复杂性和准确性，0~1
          - 值越大轮廓点越多，越准确
        - Generate: 生成网格轮廓
          - 也可以手动增删/拖动这些点来调整
    - Custom Physics Shape（决定碰撞判断区域）
      - 设置图片物理碰撞检测的形状
      - 和上面这个渲染边缘的设置方法相同
    - Skinning Editor
      - 精灵图没有骨骼动画是不会有这个选项的
      - 以后再讲
    - Secondary Textures(为图片添加特殊效果)
      - 次要纹理设置,配合着色器,Shader使用实现效果
      - 以后不讲
- Multiple图集编辑
  - ![image-1](https://document-image.mubu.com/document_image/32569566_2c3d9e0c-cfdc-4a92-f944-b73bc1f6f2ce.png?x-tos-process=image/resize,w_400)
    - 图集需要分割
  - 图集切割后才会出现SpritieEditor右下角窗口,而且可以改name,position
    - position决定的小图在图集上的位置
  - 主要是左上角多了个Slicer
    - 通用设置
      - Pivot轴心点
        - 注意影响的不是图集的轴心,而是切割后每一张小图的轴心
      - Method自动切割如何处理现有的切割矩形
        - Delete Existing: 替换掉已经选择的任何矩形
        - Smart: 尝试创建新矩形同时保留或调整现有矩形
        - Safe: 添加新矩形而不更改任何已经存在的矩形
    - Type切割类型
      - Automatic(自动分割)
        - Unity帮你导
      - Grid By Cell Size(按单元格大小分割)
        - 手动设定方格偏移量,大小,各方格之间的距离等
        - Pixel Size: 单元格宽高
        - Offset: 偏移位置
          - 相对图集左上角的偏移
        - Padding: 和边缘的偏移位置
          - 两个矩形间距离
        - Keep Empty Rects: 是否保留空矩形
          - 比如有个矩形里面压根没有图,选择是否还要保留这个矩形
      - Grid By Cell Count(按单元格数量分割)
        - 可以设置几行几列
  - Trim
    - 自动调整矩形大小,减少透明区域
- Polygon多边形编辑
  - ![image-1](https://document-image.mubu.com/document_image/32569566_af357718-efbb-432f-a31b-f62c52f81b90.png?x-tos-process=image/resize,w_400)
    - 实际开发用的很少
  - Editor中只有个Sides可以编辑
    - 就是设置多边形边数,3~128
    - 可能就是你有多边形图标比较多的时候,用起来方便点吧hh
