- 图片导入设置细讲
  - 纹理类型
    - ![image-1](https://document-image.mubu.com/document_image/32569566_f605fe47-d9c3-40df-adab-1b15932fcfa4.png?x-tos-process=image/resize,w_400)
      - (空)
    - Default	啥都能用的通用贴图
      - sRGB
        - ![image-1](https://document-image.mubu.com/document_image/32569566_e71b07ba-d906-47aa-9d33-bace9bec7f1c.png?x-tos-process=image/resize,w_455)
        - ![image-1](https://document-image.mubu.com/document_image/32569566_f89f5e0a-f42c-4c97-cf62-d489de898488.png?x-tos-process=image/resize,w_400)
        - 总之就是人眼看线性变化有偏差,显示器要对应调整,叫做伽马校正
        - 所以sRGB就是用于校准画面颜色线性变化的偏差
      - Alpha Source
        - ![image-1](https://document-image.mubu.com/document_image/32569566_712cb833-2760-421a-b0f7-ba256505eaca.png?x-tos-process=image/resize,w_400)
          - 选项1,2就是是否带有透明A通道
          - 选项3用的比较少,是通过RGB计算生成A
        - 指定如何生成纹理的Alpha通道
        - Alpha就是RGBA里面的A透明度
          - 对扣掉的图片来说,这个图片就是决定是实心的图片还是扣掉背景的
      - Alpha Is TransParently
        - 启用可以避免边缘上的过滤瑕疵
        - 反正一般启用就行了
    - Normal map	让模型有凹凸感的法线贴图
      - ![image-1](https://document-image.mubu.com/document_image/32569566_6614241e-89b2-451a-8807-ca31e26ee890.png?x-tos-process=image/resize,w_400)
        - 通过法线(垂直于某一点的法线向量),实现物体凹凸表面
        - 普通模型为了减少面片数,可能会合并三角面片,导致画面精度丢失
          - 也就是粗糙低模
          - 通过法线贴图就可以补充低模的精细信息
        - ![image-1](https://document-image.mubu.com/document_image/32569566_486fe769-40e0-4388-a101-4b84fa9a833a.png?x-tos-process=image/resize,w_400)
          - 就那种视错觉绘画,不需要实际有凹凸的胡子,看起来像就行
      - Create From Grayscale
        - 启用此属性可以从灰度高度贴图创建法线贴图(就是控制法线效果而已)
        - Bumpiness
          - 控制凹凸程度，值越大凹凸感越强
        - Filtering
          - 如何计算凹凸值
          - Smooth: 使用标准算法生成法线贴图
          - Sharp: 生成比标准模式更锐利的法线贴图
    - Sprite	2D 游戏、UI 精灵
      - 2D游戏,UGUI中可以使用
      - ![image-1](https://document-image.mubu.com/document_image/32569566_123cebb1-94a7-4db4-a6a4-237846051189.png?x-tos-process=image/resize,w_400)
      - Sprite Mode:图像中提取精灵图形的方式
        - Single：按原样使用精灵图像
        - Multiple：瓦片模式，如果是图集，使用该选项，可以在 Sprite Editor 编辑窗口自定义图片
        - Polygon：网格精灵模式,用的不多
          - ![image-1](https://document-image.mubu.com/document_image/32569566_b49abe1b-9032-41fd-db72-49283a8ab6f0.png?x-tos-process=image/resize,w_400)
      - Pixels Per Unit:世界控件中的一个单位对应多少像素
        - 设定为100就是一个单位(1米)对应100像素
      - Mesh Type:网格类型；只有 Single 和 Multiple 模式才支持
        - Full Rect：创建四边形，将精灵显示在四边形上
          - ![image-1](https://document-image.mubu.com/document_image/32569566_828d76bd-415b-4f0b-b5a4-627d90cc8366.png?x-tos-process=image/resize,w_92)
          - 创建一个三角形就是显示在两个三角面片组成的四边形上
        - Tight：基于像素 Alpha 值来生成网格，更加贴合精灵图片的形状；
          - ![image-1](https://document-image.mubu.com/document_image/32569566_7dcef822-963c-4717-82ad-9a9865d8d221.png?x-tos-process=image/resize,w_108)
          - 三角形周围是透明的,直接在内部生成网格
          - 任何小于 32*32 的精灵都使用 FullRect 模式,即使设置成 Tight 模式也是
            - 说人话就是图片太小只能用四边形承载显示
      - Extrude Edges:使用滑动条确定生成的网格中精灵周围流出的区域大小
        - ![image-1](https://document-image.mubu.com/document_image/32569566_ee4d2a12-7e97-4fef-9214-9d3fb78d8bc7.png?x-tos-process=image/resize,w_131)
        - 可能会溢出一些区域用于生成网格
      - Pivot:精灵图片的轴心点，Single 模式才有此选项
        - 还可以自定义custom
      - Generate Physics Shape:启用此选项，Unity 会自动根据精灵轮廓生成默认物理性状
        - 只有 Single 和 Multiple 模式才可使用(Plygon本来就是生成对应轮廓)
    - Cursor	自定义鼠标光标
      - 就是可以设定鼠标,额,没啥东西
    - Cookie 光源剪影格式
      - ![image-1](https://document-image.mubu.com/document_image/32569566_d654869f-0fcc-444f-abf7-655364d9dbce.png?x-tos-process=image/resize,w_400)
      - 就是之前的设置灯光遮罩效果
      - 注意三种光源类型对应的纹理形状不同
        - 具体下节课再讲
      - AlphaSource选项和之前一样的作用
    - Lightmap	烘焙光照的专用贴图
      - 后面讲
    - Single Channel纹理只需要单通道格式
      - ![image-1](https://document-image.mubu.com/document_image/32569566_1beb9f43-819c-4548-bff8-8ddfdbf26e74.png?x-tos-process=image/resize,w_400)
      - Channel: 希望将纹理处理为 Alpha 还是 Red 通道
        - Alpha: 使用 Alpha 通道，不允许进行压缩
        - Red: 使用红色通道
      - 好吧也是短时间用不到,以后再用吧
    - Cubemap	天空盒、环境反射贴图

    - Texture Shape: 纹理形状
      - 2D：2D 纹理
        - 最常用,这些纹理将使用到模型和 GUI 元素上

  - 高级设置
    - ![image-1](https://document-image.mubu.com/document_image/32569566_ea2f4886-65ea-4047-f900-dbdaafc441d3.png?x-tos-process=image/resize,w_359)
    - ![image-1](https://document-image.mubu.com/document_image/32569566_4832fbd8-0d7d-4dc4-ae38-76b765a6ad0b.png?x-tos-process=image/resize,w_358)
      - 说人话MipMap就是把图片生成n张不同分辨率的版本
      - 在场景中根据我们离模型的距离选择合适的尺寸图片来渲染,提升效率
    - ![image-1](https://document-image.mubu.com/document_image/32569566_a75c3f51-e365-425b-c5d8-3d69c4a94195.png?x-tos-process=image/resize,w_400)
      - 图形学规定纹理必须是2^n变长比如128*128
    - Non Power of 2: 如果纹理尺寸非 2 的幂如何处理
      - None: 纹理尺寸大小保持不变
      - To nearest: 将纹理缩放到最接近 2 的幂的大小（注意: PVRTC 格式要求纹理为正方形）
      - To larger: 将纹理缩放到最大尺寸大小值的 2 的幂的大小
      - To smaller: 将纹理缩放到最小尺寸大小值的 2 的幂的大小
    - Read/Write Enabled: 启用可以使用 Unity 中提供的一些方法,从纹理中获取到数据
      - 一般需要获取图片数据时才开启,不然会有额外性能开销
    - Streaming Mipmaps: 启用则可以使用纹理串流
      - 主要用于控制加载在内存中的 Mipmap 级别，用于减少 Unity 对于纹理所需的内存总量，用性能换内存
      - Mip Map Priority:Mipmap优先级
        - Untiy根据优先级确定分配资源时优先考虑哪些Mipmap
    - Generate Mip Maps: 允许生成 MipMap
      - ![image-1](https://document-image.mubu.com/document_image/32569566_dcb7200d-4234-4419-ab6a-adccd263257a.png)
        - 点击右上角就可以查看不同分辨率的MipMap
      - 2D游戏就一个平面,一般不用开启
        - 3D游戏看性能消耗情况
      - 这些参数看看就行,不重要
        - Box: 随着尺寸减小，级别更加平滑
        - Kaiser: 随着 Mipmap 尺寸大小下降而使用的锐化算法，如果远处纹理太模糊，可以使用该算法
        - Mip Maps Preserve Coverage: Mipmap 的 Alpha 通道在 Alpha 测试期间保留覆盖率
        - Alpha Cutoff Value: 覆盖率参考值
        - Fadeout Mip Maps: 级别递减时使 Mipmap 淡化为灰色
  - 纹理拉伸
    - ![image-1](https://document-image.mubu.com/document_image/32569566_913c5edb-00b0-4014-c793-230bb62f471b.png?x-tos-process=image/resize,w_400)
    - ![image-1](https://document-image.mubu.com/document_image/32569566_5c6c668a-05e8-423f-d50c-fbfcf7bd416f.png?x-tos-process=image/resize,w_400)
      - Tiling就是一个面片排列几行几列的图片
      - offset就是图片在面片上的偏移
      - 然后根据下面的WrapMode就有不同的排列方法
    - Wrap Mode: 平铺纹理时的方式
      - Repeat: 在区块中重复纹理
        - 啊,就是黑道复制人那种排列
        - ![image-1](https://document-image.mubu.com/document_image/32569566_098cd569-223e-4046-fe14-554c050b4e28.png?x-tos-process=image/resize,w_106)
      - Clamp: 拉伸纹理的边缘
        - ![image-1](https://document-image.mubu.com/document_image/32569566_ab8eb6a8-076b-4e90-8ceb-5d5a773acc41.png?x-tos-process=image/resize,w_85)
      - Mirror: 在每个整数边界上镜像纹理以创建重复图案
      - Mirror Once: 镜像纹理一次，然后将拉伸边缘纹理
      - Per-axis: 单独控制如何在 U 轴和 V 轴上包裹纹理
    - Filter Mode: 纹理在拉伸变化大小时如何进行过渡
      - Point: 纹理在靠近时变为块状
      - Bilinear: 纹理在靠近时变得模糊
      - Trilinear: 与 Bilinear 类似，但纹理也在不同的 Mip 级别之间模糊
    - Aniso Level: 以大角度查看纹理时提高纹理质量。性能消耗高
