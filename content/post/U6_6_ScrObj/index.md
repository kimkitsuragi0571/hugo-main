        - 啊,这个好像课里干脆没讲我草,但是这个静态方法又挺重要的吧
          - 好吧非持久化里面才讲
        - `ScriptableObject.CreateInstance<T>()`
          - 父类ScriptableObject的静态方法
          - 我写的GameData类不能new实例
            - <mark style="background-color:#fef3c7;">继承了Mono的也不能new实例,一定注意区分</mark>
            - <mark style="background-color:#fef3c7;">没有继承基类的C#脚本可以new</mark>
          - 这里就填入GameData泛型
        - 两种用法
          - 1.只是`GameData tempData = ScriptableObject.CreateInstance<GameData>();`
            - 只在内存里，不保存成文件，不用了就被 GC 回收
            - 没有.asset 文件
          - 2.再写个`AssetDatabase.CreateAsset(tempData, "Assets/MyData.asset");`
            - 不会被 GC
            - 生成数据文件,永久保存在项目里
- 数据文件的使用
  - ![image-1](https://document-image.mubu.com/document_image/32569566_2f82ea86-cdd9-46a8-e435-f290961c72ad.png?x-tos-process=image/resize,w_400)
  - 法1:另一个脚本中`public GameData data;`
    - 在另一个脚本中声明GameData对象,然后挂载
      - 两个脚本均没有限定在某个命名空间里的话,直接声明脚本对象就行
      - 假如你GameData类写在Func命名空间中
        - using Func;
        - 或者用Func.GameData
    - 之后即可在面板上挂载制作的.asset文件
  - 法2:另一个脚本中`data = Resources.Load<GameData>("游戏数据");`
    - 必须放在 Assets/Resources/ 文件夹里
      - 如果你放AB包,Addressable也是可以的,用对应方式加载
    - 如果是Res下Data子文件夹中"Data/游戏数据"
  - 补充
    - 当右键创建数据.Asset文件时,会调用其脚本中Awake()函数
      - 没继承Mono所以没有Start/Update等周期函数
      - 但是仍然有特殊回调函数,比如Awake(),OnEnable(),OnDisable(),OnDestroy()
      - 还有个OnValidate(),当加载脚本或者面板中修改值时调用
    - 优势
      - ![image-1](https://document-image.mubu.com/document_image/32569566_df5e20f8-22b1-44de-c29c-019798a50c48.png?x-tos-process=image/resize,w_400)
        - 并非持久
          - 只是编辑器模式下的持久,发行后就不会保存
          - 也就是编辑模式下,你这里修改对象成员,数据.Asset文件中成员也被修改
            - 下次运行时候默认值变了(数据实现保存)
          - 等游戏发行后,这些数据并没有保存到本地,下次运行还是初始值
            - 并没有实现真正的数据持久化,所以Unity进阶里讲
        - 数据复用
          - 多个对象关联同一个数据容器文件,对其中一个对象修改,其他对象也能看见
          - 而且多个对象关联同一个数据文件,节省空间
- 非持久化数据
  - 概念
    - 就是编辑器模式和发布后均不会持久化的数据,类似于直接new一个结构数据类对象
  - 使用
    - 就是之前的CreateInstance方法
      - `GameData data = ScriptableObject.CreateInstance("GameData") as GameData;`
        - 非泛型的方法,借过一下
      - `GameData data = ScriptableObject.CreateInstance<GameData>();`
        - 运行后,脚本动态挂载了.Asset对象
        - 这种方法创建的数据文件相当于是全新new的一个,和我们文件夹中的数据文件没关系,所以默认值也和其不一样,取决于我们声明脚本时的值
        - 没有存到本地,不可以持久化
  - 意义
    - 运行时动态创建的数据,运行完就释放了
    - 只在运行时使用,不会占用硬盘空间
