- 生命周期函数
  - 概念
    - 帧
      - 游戏的本质就是一个死循环,每个循环帧里面处理特定逻辑
        - Unity底层已经做好了所谓死循环(以后就不需要使用while循环了)
    - 生命周期
      - ![image-1](https://document-image.mubu.com/document_image/32569566_33945ea5-f6d9-4ed1-8456-328103c73793.png?x-tos-process=image/resize,w_400)
      - 总之就是一些固定名字的函数,Unity会在死循环中自动调用
  - 使用
    - 修饰符
      - ![image-1](https://document-image.mubu.com/document_image/32569566_dede74a7-d2c4-4658-c5bc-1c66d2d7c6a2.png?x-tos-process=image/resize,w_400)
        - 有子类的时候就protected,没有就private
    - 这些都是生命周期函数
      - ![image-1](https://document-image.mubu.com/document_image/32569566_5eb18a3e-1959-4573-f8e0-af99694cf980.png?x-tos-process=image/resize,w_222)
        - Awake
          - 对象被创建时才会调用该生命周期函数
          - "创建对象"指的是类对象被实例化的时候,不是创建GameObject
            - 也就是脚本挂载到物体上,此时类被实例化
          - 作用类似构造函数
          - 只调用一次
        - OnEnable
          - 脚本挂载的GameObj激活的时候调用
            - 面板里面勾选就调用
            - 注意控制台里面Collapse指的是折叠重复的打印信息
        - Start
          - 在Awake()后面,第一帧更新之前更新
          - 同样只调用一次
        - FixedUpdate
          - 物理更新
          - 同样是"每一帧"执行,但是这个帧是固定时间间隔的帧
            - ProjectSetting里面Time可以修改间隔帧数
        - Update
          - 逻辑帧更新,每帧执行
        - LateUpdate
          - 每帧执行,Update之后执行
          - 摄像机位移啥的就放这里面,防止黑屏闪烁
        - OnDisable
          - 每次对象失活时才会调用
          - 对象失活时,所有生命周期函数都会停止调用
            - 没激活的对象所有的脚本都不会执行
        - OnDestroy
          - 对象被销毁的时候才会调用
      - 一定要继承MonoBehavior脚本才有生命周期函数
      - 不在其中写逻辑就不要写这个生命周期函数,有额外开销
    - 生命周期函数支持继承多态
      - ![image-1](https://document-image.mubu.com/document_image/32569566_31588b54-f83a-4f44-b2d4-136adc1c47bd.png?x-tos-process=image/resize,w_400)
        - 写个脚本继承了Lesson1类/脚本中的内容
        - 挂载后会调用父类脚本中的内容
