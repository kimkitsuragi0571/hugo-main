- 语法相关
  - var的两种作用
    - var作为隐式类型
      - <mark style="background-color:#fde8e8;">1.只能声明方法内的局部变量,不能作为类成员,也不能写在参数列表中</mark>
      - <mark style="background-color:#fde8e8;">2.必须初始化而且指定类型后不能改动类型</mark>
        - `var age = 18;`之后不能`var age = "Hi";`
      - 3.var属于编译时确定类型，dynamic属于运行时确定类型
    - <mark style="background-color:#fde8e8;">var生成匿名类型</mark>
      - `var stu = new { name = "jackie", age = 10 };`
        - 这里<mark style="background-color:#fde8e8;">只能有成员变量,如果设定个成员方法比如Speak()就报错</mark>
        - 用的同样是初始化器
      - `Console.WriteLine(`[stu.name](http://stu.name)`)`
  - 初始化器
    - 设置对象初始值
      - `Student stu = new Student { name = "jackie", age = 18 };`
        - 直接通过名称指定字段(构造函数传入的是参数)
          - <mark style="background-color:#fef3c7;">不需要指定所有字段</mark>
        - <mark style="background-color:#fef3c7;">注意写在方法体而不是参数列表里面,和构造函数属于两种路线</mark>
      - `Student stu = new Student("john",19) { name = "jackie"};`
        - 同时有构造器/初始化器,优先调用构造器(构造函数)
    - 设置集合初始值
      - ![image-1](https://document-image.mubu.com/document_image/32569566_fafe8c26-d18a-4fde-9c15-2210e7ae71e2.png?x-tos-process=image/resize,w_356)
        - List,Dictionary都可以
  - 可空类型
    - `int age = null`不行,`int? age = null`行
    - 初始值
      - `int? value;`
        - <mark style="background-color:#fef3c7;">做为类成员,没有初始化,默认值null</mark>
        - <mark style="background-color:#fef3c7;">写在方法内,没有默认值</mark>
      - `int age;`
        - <mark style="background-color:#fef3c7;">如果作为类成员,默认值0</mark>
        - <mark style="background-color:#fef3c7;">如果写在方法内没有默认值(比如main方法)</mark>
    - 可空类型方法
      - `value.GetValueOrDefault(99)`
        - <mark style="background-color:#fde8e8;">如果为null,返回括号中指定的值99</mark>
          - <mark style="background-color:#fde8e8;">注意不是给value赋值,而是返回另一个值99</mark>
        - 如果括号里没写,就默认返回0
    - 可空引用类型
      - `stu.Speak()`
        - 如果stu=null,这里报错
      - `stu?.Speak()`
        - 允许调用空的Student类型对象stu内置方法Speak()
        - 当然只是编译期不报错,实际还是没法用的
  - 内插字符串
    - `Console.WriteLine($"我是{name}");`
      - 和format差不多作用
- 栈堆进一步理解
  - 概念
    - 类/接口/委托/string/数组 就这几个引用类型
    - 上中下层语句块
      - 额,感觉没啥看的
  - 变量生命周期
    - 引用和值类型的周期
      - `int i2 =1;`
        - 刚入栈是1和i2两块区域,后面1放入i2容器
          - 最后是栈上i2和1同一块区域
        - 函数执行完毕就弹出栈
          - 栈先入后出,所以是str2先弹出
      - `string str2 = "123";`
        - 函数执行完毕str2弹出栈
          - 堆中对象"123"并未被回收,没有引用所以变成了垃圾
    - 代码块用于决定生命周期
      - ![image-1](https://document-image.mubu.com/document_image/32569566_dfb247ba-da35-4d93-d059-8f4d33424150.png?x-tos-process=image/resize,w_158)
        - 这里没写函数,但是有代码块{},所以被识别为内部变量b
        - 代码块执行完毕,b就被弹出去了,所以这里打印语句报错
      - ![image-1](https://document-image.mubu.com/document_image/32569566_98dc26bf-a331-4179-8e34-e38a8f28497d.png?x-tos-process=image/resize,w_162)
        - 这里就是反复弹出压入栈顶,显然浪费
        - 这里也没法static int b
          - 因为静态变量只能写在类里面且方法外面
      - ![image-1](https://document-image.mubu.com/document_image/32569566_51decd88-8d52-4651-9054-25364afd1efe.png?x-tos-process=image/resize,w_124)
        - 如果不想变垃圾,就要更高层级记录/使用静态全局变量记录
        - 这里并没有重新声明局部变量,而是在外部变量b上修改
          - 最终结果b=1
  - 值/引用套娃使用时
    - 值类型看大哥,引用类型始终在堆
      - 类中的值类型:就是堆中存储具体值
    - 值类型中的引用类型实例
      - ![image-1](https://document-image.mubu.com/document_image/32569566_b3967a9e-91ec-4e35-e8de-e52500930a50.png?x-tos-process=image/resize,w_188)
      - stu对象本身永远是存放在堆中
      - 栈上则负责存放地址
    - 引用类型中的值类型
      - ![image-1](https://document-image.mubu.com/document_image/32569566_5be98b64-1b84-4060-f5cc-dea47894b72e.png?x-tos-process=image/resize,w_133)
      - 值类型变量age直接存放在堆(的对象内存)中
        - 没有任何拷贝
    - 引用类型中的引用类型
      - ![image-1](https://document-image.mubu.com/document_image/32569566_332edf32-5b03-40bb-c9ba-d454b01c05f5.png?x-tos-process=image/resize,w_197)
      - 引用类型变量name具体值"jackO"存放在另一块堆内存中
        - Student实例对象中存放name的地址
    - 值类型中的值类型
      - 比如结构体中的结构体
    - 还有两个整蛊的
      - 循环引用(互相包含)
        - 引用类型 中的 值类型 中的 引用类型
        - ![image-1](https://document-image.mubu.com/document_image/32569566_6d9815ad-ef31-4f84-8a2d-aa123893c71b.png?x-tos-process=image/resize,w_218)
          - Student堆中内存含有Team结构体
          - Team结构体中含有引用变量stu,但是这个引用没有指向其他地址
            - 如果stu = new Student()
            - 就会指向堆中另一块内存
      - 数组存放内容
        - 数组本身就是引用类型,成员肯定在堆中
        - -
          - <mark style="background-color:#fef3c7;">如果是int[]值类型数组</mark>
            - <mark style="background-color:#fef3c7;">成员中存放具体值的内容</mark>
          - <mark style="background-color:#fef3c7;">如果是object[]引用类型数组</mark>
            - <mark style="background-color:#fef3c7;">成员中指定存放具体值值的堆中地址</mark>
      - 结构体继承接口
        - <mark style="background-color:#fde8e8;">接口引用类型,结构体值类型,必须把结构体装箱到堆中</mark>
        - <mark style="background-color:#fde8e8;">实际就是结构体被复制了一份，复制出来的这份进了堆</mark>
