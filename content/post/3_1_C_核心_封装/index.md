- 各种数据类型的默认值
  - | 类型类别 | 具体类型 | 默认值 | 备注 |
    | --- | --- | --- | --- |
    | 整数类型 | int | 0 | short/long/byte/sbyte 同理，都是 0 |
    | 浮点类型 | float | 0.0f | double 是 0.0，decimal 是 0.0m |
    | 布尔类型 | bool | false | 只有 true/false 两种值 |
    | 字符类型 | char | '\0'（空字符） | 对应 ASCII 码的 0 |
    | 字符串类型 | string | null | 引用类型，默认无指向 |
    | 枚举类型 | 自定义枚举（如 E_sexType） | 枚举的第一个值 | 比如 E_sexType 默认是 male（如果 male 是第一个） |
    | 结构体（值类型） | 自定义 struct（如 position） | 所有成员取默认值 | 比如 position 的 x/y/z 都是 0 |
    | 类（引用类型） | 自定义 class（如 Student） | null | 栈区变量无指向，堆区无对象 |
    | 数组 | 任意数组（如 int []） | null | 引用类型，默认无指向 |
    | 可空类型 | int?/bool?（如 int? num） | null | 专门用来存 “无值” 的类型 |
  - 直接Console.writeLine((default(int)));就可以查看其默认类型
    - char和Person这种默认null,打印出来啥都看不见

      - <mark style="background-color:#fef3c7;">GC垃圾回收机制</mark>
        - 垃圾是啥
          - ![image-1](https://document-image.mubu.com/document_image/dbd546ab-93c3-464c-a862-1db7f76a5321-32569566.jpg?x-tos-process=image/resize,w_400)
          - 也就是栈里的指针变成null,堆里的内存就是垃圾了
            - <mark style="background-color:#fef3c7;">栈的内存是系统自动分配的(有生命周期),不需要手动管理</mark>
        - GC原理
          - ![image-1](https://document-image.mubu.com/document_image/32569566_3641ce50-dbc8-498f-c0e9-9d8ef4ec4316.png?x-tos-process=image/resize,w_400)
            - 0代的回收
              - ![image-1](https://document-image.mubu.com/document_image/32569566_90f0f599-9571-4117-9828-a9dc2e5315e9.png?x-tos-process=image/resize,w_241)
              - 搬迁对象压缩堆和修改引用地址
                - 其实就是把1代中间断的那些对象压缩的紧凑点,变成连续内存
                  - 链表变成顺序表是吧
                - 此时还需要修改指针指向的地址
              - 有引用的就放到1代内存中,没引用的当垃圾回收内存
              - 有新对象的时候,如果0代内存满了,就检查哪个是没有引用的
                - (也就是堆中的内存没有对应栈中的指针)
            - 1代的回收
              - 一直移动,等到1代内存也满了的时候,就移动到2代内存中
                - 0,1代的回收速率也要比2代普遍快很多
                - 因为0,1代需要经常释放?
            - 大内存一般放在2代中
              - 因为0,1代经常释放,计算大内存就很消耗时间
          - <mark style="background-color:#fef3c7;">手动执行GC</mark>
            - 要是每次都满了才释放,玩起来容易突然卡的批爆
            - ![image-1](https://document-image.mubu.com/document_image/4b2a6a1f-50d2-4311-8171-0c6a606178c1-32569566.jpg?x-tos-process=image/resize,w_276)
