- 委托
  - 基本使用
    - 申明
      - `public delegate void Stu_Del();`
        - 1.可以写在class或者namespace中
          - 可以在类中声明,但是<mark style="background-color:#fef3c7;">不能在方法中声明,所以写在Main主方法中报错</mark>
          - 同样不能申明在方法内部的
            - ![image-1](https://document-image.mubu.com/document_image/32569566_e6189b5f-10ce-4bea-c2dd-c88f84d5d398.png?x-tos-process=image/resize,w_249)
              - 枚举可以写在类内部,但是不能写在方法里面
        - 2.这个就是声明了一个无参无返回值函数的容器
          - `public delegate int Stu_Del(int x);`
          - <mark style="background-color:#fde8e8;">只是定义个规则,并不是函数,所以这里重名了但是没法实现重载</mark>
          - <mark style="background-color:#fde8e8;">所以不能有重名委托</mark>
        - ![image-1](https://document-image.mubu.com/document_image/782631b8-73d9-4b50-a3dc-1a67fe6ee23b-32569566.jpg?x-tos-process=image/resize,w_400)
          - 1.<mark style="background-color:#fde8e8;">委托类型声明</mark>不能放在方法中
            - <mark style="background-color:#fde8e8;">委托本身是一种类型,而非成员</mark>
            - <mark style="background-color:#fde8e8;">前面这句是类型声明,原理是嵌套类,所以不能放在方法中</mark>
          - 2.委托实例声明如果放在方法中,这个委托del_id就是该方法独享
            - 想在其他方法中调用就不行
    - 调用
      - 类外绑定+调用委托
        - ![image-1](https://document-image.mubu.com/document_image/ae89ea21-05d6-402c-bfbe-a50b011d99f5-32569566.jpg?x-tos-process=image/resize,w_328)
          - 1.修饰符
            - ![image-1](https://document-image.mubu.com/document_image/32569566_d8a17fb9-d867-4d48-815e-5b7d4b73988a.png?x-tos-process=image/resize,w_400)
            - 1.首先类外访问委托是 类名.委托
              - 原理是嵌套类(和静态实例无关)
            - 2.类中委托类型声明默认private
              - 所以这里写`delegate void Stu_Del();`默认private
              - 类名.委托 的方法也没法直接访问
          - 2.绑定方法
            - 只写名字没有()
            - 仍旧普通方法从实例中写,静态方法直接类名
          - 3.使用时机
            - 这里SayHi是实例方法,如果委托实例声明写在类内部就报错
              - 因为先于构造函数执行,还没有实例呢
              - 但如果SpeakHi是静态方法,直接在类里面写委托实例声明也行
            - 总结
              - 类内使用只能是绑定的静态方法
              - 实例方法只有两种绑定时机
                - 类外使用,此时委托要指定类名
                - 构造函数中使用
                  - 类内部可以直接写`Stu_Del del;`
                  - 构造函数里面`del = new Stu_Del(SpeakHi);`这里就可以是实例方法
      - 如果是通过类中public方法调用委托
        - ![image-1](https://document-image.mubu.com/document_image/32569566_b72baa36-ec1c-4f87-e8de-08f3773e41c1.png?x-tos-process=image/resize,w_255)
          - 类内调用的标准形式,其实加个this好点

- 事件
  - 作用
    - 基于委托存在,用于封装委托(提高其安全性)
    - <mark style="background-color:#fde8e8;">实现实例隔离(每个对象有专属订阅)</mark>
      - 我草这么重要的知识点你都不讲????
      - <mark style="background-color:#fef3c7;">委托是类型,事件则是实例对象</mark>
        - 详细解释看下面的"外部调用"笔记
    - <mark style="background-color:#fce7f3;">委托是可以存放方法的变量,事件相当于被限制了权限的委托</mark>
      - 联系下面的声明语法
  - 声明
    - 语法
      - ![image-1](https://document-image.mubu.com/document_image/52cdda69-2ba5-4478-ac92-4cd22c6b1a8a-32569566.jpg?x-tos-process=image/resize,w_400)
        - event后面的不是返回值而是类型
        - 这里是声明了一个委托类型的事件
          - 事件本身不是委托
          - 但事件的 “类型” 是委托类型
    - 限制
      - ![image-1](https://document-image.mubu.com/document_image/32569566_06099893-63f0-4b7d-dad4-da2637a0796e.png?x-tos-process=image/resize,w_400)
      - <mark style="background-color:#fce7f3;">看似复杂重点似乎又只有一两个</mark>
        - 1.类中直接委托绑定非静态方法报错
          - 因为此时都还没有类实例呢,非静态方法依附实例存在
        - 2.类构造函数中绑定非静态方法可以
          - 此时实例已存在
        - 3.事件和委托的规则完全相同
  - 调用
    - 总结下
      - +
        - <mark style="background-color:#fce7f3;">Main里(外部)声明+绑定</mark>
          - 委托可以直接在Main里面声明委托实例+绑定方法
            - `Student.StuDel del = stu.SpeakHi;`
          - +
            - 事件不能在Main里面(方法内部)声明
              - `public event StuDel eve;`只能在Student类里面声明
            - 事件可以在外部绑定
              - `stu.eve+= stu.SayHello;`绑定的是具体实例
              - 静态方法Student.eve也是可以的,但是没法实例隔离
        - Main里(外部)调用
          - 如果是委托,都是直接用
            - 类中直接委托绑定静态方法
              - `Student.StuDel();`即可
              - 没法绑定实例方法
            - 构造函数中绑定实例方法
              - `stu.StuDel();`即可
          - 事件,Main中没法直接调用,需要订阅
            - 只能类内部调用,所以可以写个成员方法专门调用事件
            - Main里面调用方法即可
      - +
        - 委托也可以实现实例隔离
          - 普通写法是局部委托,不隔离
            - ![image-1](https://document-image.mubu.com/document_image/32569566_b650fd94-71c4-474b-f744-3b54682bd94a.png?x-tos-process=image/resize,w_400)
              - del只是Main里的临时变量
          - 委托作为类成员,就能实现实例隔离
            - 类里面写`public StuDel Normaldel;`
            - ![image-1](https://document-image.mubu.com/document_image/32569566_9119388e-8c10-426f-dab3-4a25ab7240b6.png?x-tos-process=image/resize,w_324)
              - 这样委托NormalDel属于单个实例stu
        - 事件必定是实现了实例隔离(静态不算)
          - 事件不能在 Main / 方法里声明,自然没法局部
          - 静态事件还是没有实例隔离的哈
          - 类里面写`public event StuDel StuEve;`
