- 基本控件
  - 选择框
    - 多选框
      - 多选题,可以同时有多个按钮可以激活/失效
      - 普通样式
        - `private bool isSel;`
        - `isSel = GUI.Toggle(new Rect(0, 0, 100, 30), isSel, "效果开关");`
          - 注意这些样式同样都需要写在OnGUI中
          - 你要是直接参数中传个true,这里就是恒定勾选了
          - 点击按钮,方法返回一个true给左边的isSel,OnGUI重复执行,从而使得下一帧中参数中isSel为true
            - 再点击一次就是返回false
          - 同样可以重载传入之前讲过的各种样式
      - 自定义样式
        - `public GUIStyle;`
        - `isSel = GUI.Toggle(new Rect(0, 0, 100, 30), isSel, "效果开关",style);`
          - 添加样式后默认背景消失,手动添加背景
          - 这里直接修改宽高会影响响应区域,所以修改下面的固定宽高?
            - fixedWidth/fixedHeight
          - Toggle只有Normal和OnNormal两种状态?
            - 设置两种状态下不同的背景图片
          - 改变padding偏移相当于改段前距离
            - 先改成左侧对齐left,然后改Padding
    - 单选框
      - 单选题,只能选择多个选项中的一个
      - Unity实际只提供了多选框,单选框是基于多选框的实现
      - ![image-1](https://document-image.mubu.com/document_image/32569566_9ee680aa-1ea1-4a3d-824b-479273b4a460.png?x-tos-process=image/resize,w_400)
        - <mark style="background-color:#fde8e8;">通过一个int标识,实现一个为true,其余的选项均false</mark>
        - 比如点击选项1,if语句就会返回true,从而执行int标识设置为1,从而只有选项1的Toggle显示激活
  - 输入框
    - 普通输入
      - `private string inputStr = "请输入";`
        - GUI.Toggle返回的是bool值,这里GUI.TextField返回的是string
      - `inputStr = GUI.TextField(new Rect(0,0,10,30), inputStr);`
        - 方法返回输入string赋值给inputStr,OnGUI重复执行,在下一帧让方法中参数inputStr同样更新为输入string,从而显示
        - 如果没有左侧接收返回值,文本框中始终是默认的"请输入"
          - 因为OnGUI每一帧都会将inputStr的当前值传入嘛
      - `inputStr=GUI.TextField(new Rect(0,0,10,30), inputStr,5);`
        - 如果想要控制最大输入长度,最后新增一个参数int值就行
    - 密码输入
      - 输入密码时,输入内容会被*替代
      - `inputPW = GUI.PasswordField(new Rect(0, 50, 100, 30), inputPW, '*');`
        - 这里最后一个参数是char类型,设定用于替代输入字符的字符,比如'囧',输入密码就是囧囧囧囧囧
  - 拖动条
    - 水平拖动条
      - `private float nowValue =0.5f;`
        - 返回值是浮点数
      - `nowValue = GUI.HorizontalSlider(new Rect(0, 100, 1000, 50), nowValue, 0, 1);`
        - 后面两个参数分别设定最小/最大值,这里就是0~1之间
          - 设定为10~-10也是可以的,自动帮你算比例
        - 这里要是没有返回值,拖动条始终没法移动固定在初始的0.5f
    - 竖直拖动条
      - `nowValue = GUI.VerticalSlider(new Rect(0, 150, 50, 1000), nowValue, 0, 1);`
  - 绘制
    - 图片绘制
      - `public Rect texPos;`
      - `public Texture tex;`
      - `GUI.DrawTexture(texPos, tex);`
        - 默认只需要设置位置和贴图两个参数
        - W和H设定,说的啥设定多高就是多高,而不是Btn那种等比缩放?
      - 其余重载
        - `public ScaleMode mode = ScaleMode.StretchToFill;`
          - 缩放模式
          - StretchToFill缩放时直接拉伸填充满
          - ScaleAndCrop裁剪图片适应不同比例
          - ScaleToFit,额保持原宽高比例,按照WH中小的值来确定缩放
            - 听起来有点抽象,但是一看就明白了
        - `public bool alpha = true;`
          - 是否保持透明混合
        - `public float wh = 0;`
          - 默认是原图宽高比
        - `GUI.DrawTexture(texPos, tex, mode, alpha, wh);`
    - 框绘制
      - `GUI.Box(Rec,"Hi")`
        - 额,就是有个框
- 复合控件
  - 长得很像的两兄弟
    - 工具栏
      - `private int toolbarIndex = 0;`
      - `private string[] toolbarInfos = new string[] { "选项一", "选项二", "选项三" };`
      - `toolbarIndex = GUI.Toolbar(new Rect(0, 0, 200, 30), toolbarIndex, toolbarInfos);`
        - ![image-1](https://document-image.mubu.com/document_image/32569566_95647faa-af71-49ac-ab46-bab576cb39d1.png?x-tos-process=image/resize,w_400)
        - 默认就是选项一嘛
    - 选择网格
      - `private int selGridIndex = 0;`
      - `selGridIndex = GUI.SelectionGrid(new Rect(0, 50, 200, 30), selGridIndex, toolbarInfos, 3);`
        - 相对toolbar多了一个参数 xCount 代表 水平方向最多显示的按钮数量
        - 要是有三个按钮你这里设置xCount=2,直接换行
  - 都需要Begin和End包裹
    - 分组
      - `GUI.EndGroup();`
      - `GUI.Button(new Rect(0, 0, 100, 50), "测试按钮");`
        - 相当于中间被包裹的控件加了个父对象
      - `GUI.BeginGroup(groupPos);`
        - 注意是Begin和End配合使用
        - 用于批量控制控件位置
          - 这里设置GruopPos也能影响被包裹按钮的显示
      - `public Rect groupPos;`
    - 滚动列表
      - 就是个有滚动条的列表,网页那种
        - 相当于一个相机拍一个场景
      - `public Rect scPos;`
        - 相当于相机取景框
      - `public Rect showPos;`
        - 相当于整个场景
      - `public Vector2 nowPos;`
        - 当前滚动的偏移值
      - `nowPos = GUI.BeginScrollView(scPos, nowPos, showPos);`
        - 同样必须和end配合使用
        - 当场景>取景框W/H的时候,才会出现横/竖滚动条
      - 中间被包过的内容,我懒得写了
      - `GUI.EndScrollView();`
  - 窗口相关
    - 窗口
      - `GUI.Window(1, new Rect(100, 100, 200, 150), DrawWindow, "测试窗口");`
        - 第一个参数是窗口id序号,不能重复
          - 窗口id一样内容不同就会顶替,不存在重载
        - 第三个是参数委托,传入用于绘制窗口的函数
        - 可以设置窗口标题名
        - 虽然没有接收,但这里也是有Rect返回值的
          - 主要也没有啥要更改的内容,保留修改干啥呢
      - ![image-1](https://document-image.mubu.com/document_image/32569566_aefe6440-435c-46b5-9b32-4d9d990925e5.png?x-tos-process=image/resize,w_400)
        - 这里就是在窗口中显示了一个Btn
        - 可以在里面设置switch语句,不同窗口id显示不同内容
    - 模态窗口
      - 让该窗口在最上层,其余按钮都无法点击(弹窗广告啊)
      - `GUI.ModalWindow(1, new Rect(100, 100, 200, 150), DrawWindow, "测试窗口");`
        - 同时有模态/普通窗口时,只有先点击模态窗口
        - 同样没有返回值
    - 拖动窗口
      - `private Rect dragWinPos = new Rect(400,400,200,150);`
        - 这个就需要接收返回值了,因为要记录拖动修改
      - `dragWinPos = GUI.Window(4, dragWinPos, DrawWindow, "拖动窗口");`
        - 只是前提,还没法拖动窗口
      - ![image-1](https://document-image.mubu.com/document_image/32569566_32833961-79d6-4c15-a294-8b3c62cf56ca.png?x-tos-process=image/resize,w_400)
        - 函数中调用API,让其可以被拖动
        - 传入Rect的重载
          - `GUI.DragWindow();`
            - 默认无参重载就是所有窗口都可以拖动
          - `GUI.DragWindow(new Rect(10, 30, 180, 30));`
            - 只有点击窗口中Rect部分可以拖动
- 自定义整体样式
  - GUISkin
    - 全局颜色
      - `GUI.color =Color.red;`
        - 就算有个自定义Style的Btn 贴图,也会改成红色
        - 如果全局设置为红色,GUI.contentColor设置为黄色
          - 结果将会是二者颜色相乘叠加?
    - 文本颜色
      - `GUI.contentColor=color.yellow;`
    - 背景颜色
      - `GUI.backgroundColor=color.yellow;`
    - 整体皮肤样式
      - `public GUISkin skin;`
      - `GUI.skin = skin;`
        - 设置为null就是默认样式,想自定义就右键创造GUI Skin
        - (设置起来和GUIStyle一样)
      - `GUI.Button(new Rect(0, 0, 100, 30), "测试按钮");`
  - GUILayout
    - GUILayout自动布局
      - `GUILayout.Button("测试按钮");`
        - 不用写位置,自动向下排列
        - 按钮大小也会自动适应内部文字
        - 测试的时候用挺方便的,游戏里就算了
      - `GUILayout.EndHorizontal();`
        - 这样就是自动向左边排列了
      - 也可以整体设置自动布局的显示区域
        - `GUILayout.BeginArea(new Rect(100, 100, 100, 100));`
          - 两种都是限制排列位置,只是这种是自动排列专用,范围内的控件自动排列(Group就只是限制?)
        - `GUILayout.EndArea();`
        - `GUI.BeginGroup(new Rect(100, 100, 200, 300));`
        - `GUI.EndGroup();`
    - GUILayoutOption布局选项
      - `GUILayout.Button("测试按钮",GUILayout.Width(200));`
        - 两个参数的重载
      - ![image-1](https://document-image.mubu.com/document_image/32569566_fd20af52-b2e0-43fb-fff1-89c264273906.png?x-tos-process=image/resize,w_400)
        - 最小宽高就是你啥都不填的时候仍然有一个宽高
        - 允许拓展就是要不要和之前长的按钮对齐
